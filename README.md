# 집온 JipOn - 서비스 이용 설정

## 사용자와 목표
- 사용자: 청소 서비스 이용을 희망하는 사람
- 목표: 청소 서비스 종류를 확인하고 서비스를 신청한다.

## 사용자의 흐름
1. 개인정보 제공에 동의하고 '서비스 신청하기' 버튼을 누른다
2. 신청하고자 하는 청소 서비스를 문의 제목에 입력한다. 비어있으면 같은 단계에서 안내를 받는다.
3. 청소 서비스 이용 시간을 선택하고 필요하면 추가 문의를 포함한다.
4. 제목, 시간, 추가 문의를 확인하고 수정하거나 완료한다.
5. 설정 완료 안내를 확인하고, 필요하면 재설정 한다.

## 인터렉션 시나리오
1. 시작과 개인정보 동의 안내
- 행통, 이벤트: 기존 동의 체크박스를 선택하고 '서비스 신청하기'를 클릭한다.
- 조건: 개인정보 제공 동의가 선택되었는가?
- 반응, 다음 상태: 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 사용 목적을 설명하는 안내 팝업이 열린다.
             팝업에서 '돌아가기'를 누르거나 Esc를 누르면 동의를 해제하고 시작 화면에 남는다.
            '동의하고 설정 시작하기'를 누르면 제목 입력 화면을 연다.

2. 제목 입력
- 행동, 이벤트: 제목을 적고 '상세 조건 선택하기'를 클릭한다. 
- 조건: 앞뒤 공백을 지운 제목이 비어 있는가?
- 반응, 다음상태: 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.
                값이 있으면 저장하고 조건 선택으로 이동한다.

3. 조건 선택
- 행동, 이벤트: 서비스 이용 시간을 바꾸나 추가 문의를 선택하고 '내용 확인하기'를 클릭한다.
- 조건: 질의응답을 선택했는가?
- 반응, 다음상태: 선택했을 때만 질문 수를 보여준다

4. 내용 확인
- 행동, 이벤트: 제목, 시간, 추가 문의를 읽고 '수정하기' 또는 '설정 완료하기'를 클릭한다.
- 조건: 수정인가, 완료인가?
- 반응, 다음상태: 수정하면 기본 값을 유지하고 조건 선택으로 돌아간다.
                완료하면 완료 안내로 이동한다.

5. 완료와 재설정
- 행동, 이벤트: 완료 안내를 읽고 필요하면 '다시 설정하기'를 클릭한다.
- 반응, 다음상태: 새 설정의 제목, 시간, 추가 문의, 진행 상태를 초기화 하고 제목 입력부터 다시 시작한다.
                이미 확인한 개인정보 제공 동의와 다른 기능을 유지한다.

6. 중간고사 기능 추가 항목(서비스 이용 준비 체크리스트) 설명
- 행동, 이벤트: '방문 전 준비하기'를 누르고 준비 항목을 체크한다.
- 조건: 체크한 항목이 전체 항목과 일치하는가?
- 반응, 다음 상태: 체크할 때마다 완료 항목 수와 진행률이 변경된다.
                4개 항목을 모두 체크하면 완료 안내가 표시된다.
                체크 해제나 초기화 버튼으로 상태를 수정할 수 있으며, '신청 완료 화면으로'를 누르면 이전 화면으로 돌아간다.

7. 테스트 기록
- 정상 경로: 신청 완료 화면에서 체크리스트로 이동하고, 항목 체크 및 전체 완료 안내를 확인.
- 수정 경로: 체크 해제 및 초기화 후 진행률이 정상적으로 변경되는 것을 확인.
- 이전 화면 이동: 신청 완료 화면으로 정상 복귀하는 것을 확인.
